# Pulse

Мобильное приложение медицинского центра: пациент выбирает врача, находит свободное время и записывается на приём без звонка в регистратуру.

<img width="194" height="419" alt="изображение" src="https://github.com/user-attachments/assets/5834caf7-21d2-4acd-b19e-2a90bc183058" />

## Возможности
- Онбординг, регистрация и вход
- Каталог специальностей и врачей с поиском и фильтрами
- Профиль врача и выбор даты и времени
- Подтверждение записи
- «Мои записи»: перенос и отмена
- Профиль пациента и результаты анализов
- Русский и белорусский языки (переключение в настройках)

## Экраны
| Старт | Заставка, онбординг (2) |
| Аккаунт | Вход, регистрация, профиль пациента |
| Запись | Главная, специальности и врачи, профиль врача, дата и время, подтверждение |
| Личное | Мои записи, результаты анализов |

## Технологии
- Java, Android Studio
- XML-разметка, Android Emulator
- Дизайн: Figma
